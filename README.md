# اقرأ معي 📚

تطبيق تفاعلي لتدريب الأطفال على القراءة باللغة العربية في المرحلة الابتدائية.

## الميزات 🌟

- 📖 ثلاثة مستويات تدريبية متدرجة
- 🎤 تسجيل صوت الطفل أثناء القراءة
- 🎧 نطق واضح وبطيء مناسب للأطفال
- 🏆 نظام نقاط ونجوم وأوسمة
- 👨‍👩‍👧 متابعة ولي الأمر مع إحصائيات مفصلة
- 🎓 شهادات تقدير قابلة للطباعة
- 📱 واجهة سهلة وملونة للأطفال

## البدء السريع 🚀

```bash
# تثبيت المتطلبات
npm install

# إنشاء ملف البيئة
cp .env.example .env.local

# تشغيل قاعدة البيانات (PostgreSQL)
# تأكد من تثبيت PostgreSQL وتشغيله

# تطبيق التهيئة
npm run db:push

# تشغيل التطبيق
npm run dev
```

التطبيق سيكون متاحاً على: http://localhost:3000

## المتطلبات 📋

- Node.js 18+
- PostgreSQL 12+
- npm أو yarn

## الهيكل 🏗️

```
src/
├── app/           # صفحات التطبيق
├── components/    # مكونات React
├── db/           # قاعدة البيانات
├── hooks/        # React hooks مخصصة
└── lib/          # دوال مساعدة
```

## النشر 🌐

التطبيق جاهز للنشر على Vercel أو Railway.

### Vercel
```bash
vercel deploy
```

### Railway
1. ربط مستودعك من GitHub
2. أضف PostgreSQL
3. أضف DATABASE_URL
4. Deploy!
